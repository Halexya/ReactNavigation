# Como clonar e executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/Halexya/ReactNavigation.git
```

### 2. Entrar na pasta do projeto

```bash
cd ReactNavigation
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o projeto

```bash
npm start
```
